🛒 Mon Projet E-commerce

📌 Description

Ce projet est une petite boutique en ligne développée avec HTML, CSS et JavaScript.

Il permet de visualiser des produits, de les ajouter au panier et de gérer les quantités de chaque produit.

🚀 Fonctionnalités

- Affichage des produits disponibles.

- Ajout de produits au panier.

- Augmentation et diminution des quantités.

- Suppression de produits du panier.

- Calcul automatique du prix total.

- Sauvegarde du panier grâce à LocalStorage.

🛠️ Technologies utilisées

- HTML5

- CSS3

- JavaScript

- LocalStorage

📂 Structure du projet

mon-projet-ecommerce/
├── index.html
├── style.css
├── script.js
└── README.md

💻 Installation

- Cloner le dépôt GitHub.

- Ouvrir le dossier du projet dans VS Code.

- Ouvrir le fichier index.html dans un navigateur.
